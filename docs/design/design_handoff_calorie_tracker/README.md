# Handoff: Калькулятор калорій (Calorie Tracker)

## Overview
Персональний PWA-калькулятор калорій на двох користувачів з ШІ-аналізом їжі (Google Gemini). Цей пакет містить дизайн трьох головних мобільних екранів: **Дашборд**, **Журнал за день** та **Форма додавання їжі з ШІ-аналізом**.

## About the Design Files
Файли в цьому бандлі — це **дизайн-референси, створені в HTML** (`Калькулятор калорій.dc.html`). Це прототипи, що демонструють задуманий вигляд і поведінку, **а не продакшн-код для прямого копіювання**.

Завдання — **відтворити ці HTML-дизайни у цільовому середовищі** зі стека проєкту: **React / Next.js + Tailwind CSS + shadcn/ui + Lucide React + Recharts + TanStack Query / Zustand** на фронтенді та **NestJS + Prisma + @google/generative-ai** на бекенді (повна специфікація в `CLAUDE.md`). Використовуйте усталені патерни й бібліотеки цього стека, а не переносьте HTML напряму.

## Fidelity
**High-fidelity (hifi).** Фінальні кольори, типографіка, відступи, радіуси й тіні задані точно (див. Design Tokens). Відтворюйте UI піксель-у-піксель засобами свого стека. Mobile-first, ширина екрана — 390px, темна тема (dark mode за замовчуванням).

## Interactions & Behavior
- **Перемикач профілів:** тап по pill-хедеру → dropdown зі списком користувачів (Олег, Марія). Зміна профілю перезавантажує дашборд і журнал під `userId`.
- **Налаштування:** кнопка-шестерня → модалка (`.dialog`) з полями цільових калорій та GEMINI_API_KEY.
- **Навігація по днях:** стрілки в журналі змінюють `date` (YYYY-MM-DD), перезапитуючи `GET /api/meals`.
- **Додавання їжі:** «Розрахувати» → loading-стан (Skeleton/Spinner замість картки результату) поки `POST /api/meals` стукає в Gemini → показ картки результату → «Зберегти в журнал».
- **Видалення:** trash-іконка на картці → `DELETE /api/meals/:id`, картка зникає з плавною анімацією, тоталі перераховуються.
- **Кольори статусу дня:** `totalCalories ≤ targetCalories` → зелений; `> targetCalories` → червоний. Застосовується до стовпчиків графіка (динамічний колір) та бейджів.
- **Анімації:** плавні переходи карток (fade/slide), анімоване заповнення кільця та барів при завантаженні.

## State Management
- **currentUser** — активний профіль (Zustand); джерело `GET /api/users`.
- **selectedDate** — обраний день у журналі (YYYY-MM-DD).
- **geminiApiKey** — зберігається локально / у профілі.
- **Дані (TanStack Query):**
  - `dashboard` ← `GET /api/stats/dashboard?userId={id}` (7 днів, статуси, differences).
  - `meals` ← `GET /api/meals?userId={id}&date={date}`.
  - `analyze/create meal` ← `POST /api/meals` (loading/success/error стани).
- **Loading states:** skeleton для карток та графіка; spinner на кнопці «Розрахувати».
- **Error states:** помилка Gemini / мережі → повідомлення з ретраєм.

- **Статус red:** `#e0808c` → `#c05f6c`
- Bar track / прогрес-track: `#2b2d3a` / `#1c1e2b`

**Radius:** sm 4px, md 8px, lg 14px, pill 999px.
